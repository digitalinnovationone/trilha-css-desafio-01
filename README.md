# Desafio 01: Criando sua primeira Landing Page com HTML e CSS / Challenge 01: Creating your first Landing Page with HTML and CSS

Bem vindo(a) ao primeiro desafio da Trilha de CSS da DIO! Nela, voce vai construir sua primeira Landing Page com HTML e CSS, colocando em pratica os fundamentos do CSS, as propriedades basicas da linguagem de estilizacao, alem de trabalhar com as unidades de medidas relativas e absolutas que aprendemos ao longo da trilha.

Welcome to the first challenge of the DIO CSS Trail! In it, you will build your first Landing Page with HTML and CSS, putting CSS fundamentals into practice, the basic properties of the styling language, in addition to working with the relative and absolute measurement units we learned throughout the trail.

## Como Participar / How to Participate

Para voce realizar o desafio, basta fazer um fork para o seu GitHub e comecar a mexer no projeto.

To do the challenge, just fork it to your GitHub and start working on the project.

Dentro da pasta main, voce vai encontrar todas as imagens e o arquivo HTML, contendo a estrutura basica da sua pagina, faltando apenas realizar a estilizacao da sua pagina.

Inside the main folder, you will find all the images and the HTML file, containing the basic structure of your page, with only the styling left to do.

E necessario que voce faca toda a parte responsavel por interligar sua pagina HTML com suas folhas de estilo para que o resultado da estilizacao funcione.

You need to do all the work of connecting your HTML page with your stylesheets for the styling to work.

[Link do Figma / Figma Link](https://www.figma.com/file/3PiokoJj9IhGDnNiWAJbz7/DIO---Desafio-01?node-id=2%3A6) contendo o prototipo do desafio para que voce possa se basear. / containing the challenge prototype for you to base your work on.

*Observacoes / Notes:* para aplicar os textos em gradiente, utilize a propriedade CSS background-clip, porem, para funcionar em alguns navegadores, e necessario utilizar a propriedade -webkit-background-clip: text; / to apply gradient texts, use the CSS background-clip property, however, for it to work in some browsers, you need to use the -webkit-background-clip: text; property.

Caso tenha alguma duvida, ou queira comparar o resultado do desafio que voce fez, nos temos o site finalizado na branch final. Basta alterar a branch do projeto utilizando o comando `git checkout final` no seu terminal.

If you have any questions, or want to compare the result of the challenge you did, we have the finished site on the final branch. Just change the project branch using the command `git checkout final` in your terminal.
